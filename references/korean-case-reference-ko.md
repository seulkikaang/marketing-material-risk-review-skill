# 한국 마케팅 논란 케이스 기반 체크포인트

이 파일은 특정 사건을 단정적으로 재판단하기 위한 DB가 아니라, 한국 시장에서 반복적으로 문제가 된 리스크 패턴을 skill 검토 질문으로 전환하기 위한 레퍼런스다. 사례명은 교육·검토 목적의 키워드로만 사용하고, 실제 판단은 최신 원문·공식자료·법무 검토로 확인한다.

## Evidence Level

- `strong`: 직접 기사/기관/공식자료가 복수로 있거나 공식 대응·제재가 확인되는 유형
- `medium`: 직접 보도는 있으나 해석 논쟁 또는 맥락 확인이 더 필요한 유형
- `weak`: 사후 비판·회고 성격이 강해 규칙 참고용으로만 사용할 유형

## 반복 패턴 요약

| Pattern | Typical materials | Review question | Default action |
|---|---|---|---|
| 손모양·제스처 논란 | 포스터, 이벤트 배너, 게임/영상 프레임, 임직원 콘텐츠 | 물건을 잡는 기능적 맥락인가, 특정 제스처처럼 보이는가? | 불필요하면 수정/교체 |
| 로고·문장 변형 | 썸네일, 패러디 이미지, 합성 로고, 공식기관풍 엠블럼 | 원본 로고와 다르거나 권위를 차용하는가? | 출처/허가 확인, 법무 검토 |
| 역사·국가 상징 | 지도, 날짜 이벤트, 일본/전쟁/사회적 사건 관련 카피 | 한국 역사 맥락에서 부적절하게 읽히는가? | HIGH_RISK 검토 |

| 건강·질병 공포마케팅 | 식품, 건기식, 생활화학, 방역용품 | 예방/치료/안전성을 과장하는가? | LEGAL_REVIEW_REQUIRED |
| 가격·할인·구독 오인 | 이커머스, 앱, 랜딩페이지, 푸시 | 조건·한도·기간·자동결제가 충분히 보이는가? | REVISE/법무 검토 |
| 기사형·네이티브 광고 | 인터넷신문 배너, 랜딩페이지, 콘텐츠형 광고 | 광고와 기사/뉴스가 명확히 구분되는가? | 표시 강화 |
| 후기·인플루언서 뒷광고 | SNS, 유튜브, 블로그, 공동구매 | 경제적 이해관계가 즉시 인지되는가? | 표시 강화 |
| AI·가상인간·합성 | AI 프로필, 가상모델, 딥페이크성 콘텐츠 | 실존 인물/실제 후기처럼 오인되는가? | AI 고지/권리 검토 |

## 대표 체크포인트

### 1. 손모양·제스처

관련 유형: GS25, 무신사, 넥슨/스튜디오 뿌리, 르노코리아 등에서 보도된 손모양 논란 유형.

체크:

- 손동작이 제품 사용상 필수인가?
- 엄지-검지 간격, 손목 방향, 주변 오브젝트가 특정 제스처와 유사한가?
- 영상의 일부 프레임에만 등장하는가?
- 외주 제작물 또는 임직원 출연 콘텐츠도 브랜드 공식물로 검수했는가?

권고:

- 의도 단정 금지.
- 공개 전에는 유사 제스처를 안전한 손동작 또는 오브젝트 없는 구성으로 바꾼다.

### 2. 로고·권위 차용·변형

관련 유형: 공식기관 로고풍 이미지, WHO/UN/UNESCO류 권위 차용, 대학·브랜드·스포츠 엠블럼 변형, 패러디 로고.

체크:

- 공식기관·대학·병원·인증기관처럼 보이는가?
- 원본 로고와 조금 다르게 바꾸어 내부 의미를 바꿨는가?
- 공식 발표, 인증, 후원, 탈퇴, 선언처럼 오인될 수 있는 문구와 결합했는가?
- 로고 안에 숨은 글자, 초성, 인물, 벌레, 무기, 혐오/정치 상징이 보이는가?

권고:

- 원본·사용허가·공식 출처를 요구한다.
- 변형 로고는 `UNVERIFIED_LOGO_VARIANT`로 표시하고 법무/브랜드 검토로 올린다.

### 3. 역사·국가·재난 민감성

관련 유형: 지도 표기, 욱일기 연상 그래픽, 민감한 사회적 사건·추모일과 이벤트 결합, 식민지·전쟁 관련 표현, 5·18 기념일 `탱크데이`처럼 상품명·날짜·카피가 역사적 폭력과 결합되는 프로모션.

체크:

- 게시일·이벤트명·이미지 소재가 민감 날짜와 겹치는가?
- 단어 자체는 중립적이지만 색상·오브젝트·날짜와 결합해 사건을 연상시키는가?
- 해외 제작 소재의 지도·국가명·역사 표현이 한국 시장과 충돌하는가?
- 상품명·이벤트명·프로모션 날짜·CTA가 결합했을 때 민주화운동, 국가폭력, 고문치사, 참사, 고인을 연상시키는가?

권고:

- 날짜/이벤트명을 바꾸거나 해당 소재를 제외한다.
- 민감 날짜에 우연히 걸린 프로모션도 즉시 `HIGH_RISK`로 올리고, 앱/푸시/배너/SNS/랜딩 문구 전체를 함께 중지·재검수한다.
- 역사·영토·국가정서와 관련된 이미지는 PR/법무/지역 전문가 검토를 거친다.

### 4. 성적 대상화·아동 보호

관련 유형: 교복/아동 모델/직업복/신체 클로즈업/몰래촬영 구도/동물화 연출.

체크:

- 제품과 무관하게 신체를 강조하는가?
- 아동·청소년에게 성인적 섹슈얼 코드를 부여했는가?
- 몰래촬영, 훔쳐보기, 폭력·범죄 미화처럼 보이는가?
- 특정 직업군을 성적 이미지로 소비하는가?

권고:

- 모델 구도, 의상, 카피, 카메라 앵글을 제품 기능 중심으로 바꾼다.
- 아동/청소년 소재는 `HIGH_RISK` 기준으로 보수 검토한다.

### 5. 건강·안전·질병 표현

관련 유형: 생활화학제품 안전성, 식품/건기식 질병 효능, 방역용품 공포마케팅, 다이어트/탈모/면역 표현.

체크:

- 예방·치료·완치·무해·100% 차단 같은 표현이 있는가?
- 제품 카테고리상 허용되지 않는 의약품적 효능을 암시하는가?
- 근거자료가 있고 소비자가 확인 가능한가?

권고:

- 절대표현을 삭제하고 검증 가능한 범위로 낮춘다.
- 법무·RA·심의 검토 전 게시하지 않는다.

### 6. 가격·할인·구독·다크패턴

관련 유형: 최대 할인, 무료체험, 자동결제, 최저가, 쿠폰 조건, 배송비/수수료 누락, 앱 UX 오인.

체크:

- 혜택 문구와 조건 고지가 같은 화면·가까운 위치에 있는가?
- 무료체험 후 유료전환, 해지조건, 제외상품, 한도, 기간이 명확한가?
- 닫기/재생/다운로드 버튼처럼 보이는 광고 UI가 있는가?

권고:

- 조건을 CTA 근처에 동등한 가시성으로 표시한다.
- “최대/최저/무료” 표현은 기준과 적용범위를 즉시 명시한다.

## 공식 참고 레이어

최신 원문 확인이 필요한 규정·기관:

- 방송광고심의에 관한 규정
- 인터넷신문광고 심의규정
- 공정거래위원회 표시광고·추천보증 관련 지침
- 식품의약품안전처 식품·건강기능식품·화장품 광고 관련 자료
- 금융위원회/금융감독원 금융광고·상품설명 관련 자료
- 한국소비자원 소비자 오인·안전 관련 자료

최종 산출물에는 “해당 규정 적용 가능성 있음, 최신 원문과 법무 검토 필요”라고 표시한다.
